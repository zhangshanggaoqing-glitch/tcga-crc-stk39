# STK39 in colorectal cancer: a reproducible TCGA COAD/READ analysis

A compact, fully scripted bulk RNA-seq workflow: tumor vs normal expression, high-vs-low differential expression (limma-voom), GO/KEGG enrichment (clusterProfiler ORA + GSEA), and overall-survival analysis (Kaplan–Meier, Cox). All numbers below come from `results/` and are regenerated by `run_all.sh`.

## Data sources (public, open access)
- UCSC Xena **GDC hub**: `TCGA-COAD/READ.star_counts.tsv.gz` (STAR gene counts as log2(count+1), GENCODE v36), `*.clinical.tsv.gz`, `*.survival.tsv.gz` (OS), `gencode.v36.annotation.gtf.gene.probemap` — https://xenabrowser.net/datapages/?hub=https://gdc.xenahubs.net
- Raw data are not redistributed; `scripts/00_download.sh` fetches them (~75 MB).

## Methods (short)
- Samples: one primary tumor (barcode `-01`) and/or one solid tissue normal (`-11`) per patient → **624 tumors, 51 normals (50 matched pairs)**.
- Counts = round(2^x − 1); TMM normalisation (edgeR); STK39 = ENSG00000198648, log2 CPM.
- Tumor vs normal: Wilcoxon rank-sum (all) and signed-rank (matched pairs).
- DE: tumors split at STK39 median (312 vs 312); protein-coding genes only; `filterByExpr`; limma-voom with design `~ project + group`; STK39 itself removed from results. Significance: FDR < 0.05 and |log2FC| > 1.
- Enrichment: ORA (enrichGO BP / enrichKEGG, tested-gene universe) on DE genes; GSEA (gseGO BP / gseKEGG) on the limma moderated t ranking.
- Survival: OS; KM + log-rank (median split); Cox univariate (continuous per SD, and high vs low) and multivariable (age, sex, stage I–II vs III–IV, COAD/READ); Schoenfeld test for PH.

## Key results
| Question | Result |
|---|---|
| Tumor vs normal | median log2CPM 6.29 vs 6.41, Wilcoxon p = 0.17; paired (n=50) median Δ = −0.09, p = 0.097 → **not significant** |
| DE high vs low | 15,805 genes tested; 11,012 FDR<0.05 (mostly small shifts); **3 up / 130 down** at FDR<0.05 & \|log2FC\|>1 (down: LTC4S, TMEM121, MRPS24, MMP23B, GPS2, HDAC10, CCR10…; up: ARHGEF35, EIF3CL, CLDN2) |
| ORA | GO BP: 0 terms (down set); KEGG: 2 (Nicotine addiction; Neuroactive ligand–receptor interaction) |
| GSEA | 591 GO BP, 65 KEGG at FDR<0.05. Positive (STK39-high): nucleocytoplasmic transport, ER protein processing, cell cycle, spliceosome. Negative (STK39-low): immune/infection, cytokine, neuroactive-ligand pathways |
| Survival | n=591, 122 deaths. Log-rank p = 0.44. Cox per SD HR 0.94 (0.78–1.13), p=0.51; high vs low HR 0.87 (0.61–1.24), p=0.44; multivariable HR 0.88 (0.74–1.06), p=0.17 (n=571). PH assumption OK (global p=0.43). Stage III–IV HR 3.65, age HR 1.04/yr |

**Interpretation:** in TCGA CRC bulk RNA-seq, STK39 is not differentially expressed between tumor and normal and is not prognostic for OS. Tumors with higher STK39 show a proliferative/RNA-processing program and lower immune/stromal signal, which may reflect tumor purity rather than an STK39-specific effect.

## Limitations
Few normals (51); bulk data confounded by purity/microenvironment (no purity adjustment); arbitrary median cut-off; limited events/follow-up; OS only (no DFS/PFS); no external validation (e.g. GEO cohorts); purely correlative.

## Reproduce
```bash
Rscript scripts/install_packages.R   # R 4.5, Bioconductor 3.22
./run_all.sh
```
Environment: R 4.5.0 on Debian 13; versions in `package_versions.csv`, full `sessionInfo.txt`. System libs needed to build enrichplot deps: libfontconfig1-dev, libfreetype-dev, libharfbuzz-dev, libfribidi-dev, libcairo2-dev. Seed = 42.

## Layout
`scripts/` code (03_enrich_plots.R draws enrichment dot plots) · `results/` tables, logs · `figures/` PDF+PNG (300 dpi) · `report.html` self-contained report.
